# MindLink

**Shared Brain between Human & AI**

## Features

- Explore / Debate / **Parallel Lives** modes
- **AI Roles**: Future You, Investor, Mentor, Devil, Expert
- **Decision Memory** (localStorage)
- **Outcome Simulation** (best / likely / worst) on Lock
- Neural network background + premium loader
- Groq thinking + TTS, Pollinations images
- WebMCP tools

## Setup

```bash
cp .env.example .env.local
# GROQ_API_KEY=...
npm install
npm run dev
```

Models: `openai/gpt-oss-20b`, `openai/gpt-oss-120b`, `qwen/qwen3.6-27b`, `qwen/qwen3.8-27b`
