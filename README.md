# MindLink

**Shared Brain between Human & AI** — decisions grounded in evidence.

## Modes

| Mode | What it does |
|------|----------------|
| **Explore** | Open thinking canvas |
| **Debate** | Optimist vs pessimist |
| **Parallel** | Path A / B / C futures |
| **Research** | Idea validation — competitors, claims, gaps, market, contradictions |

## Features

- Evidence nodes with **source label** + **trust** (high / medium / low / unverified)
- AI Roles (Future You, Investor, Mentor, Devil, Expert)
- Decision Memory (localStorage)
- Outcome simulation on Lock
- Groq thinking + TTS, Pollinations images
- WebMCP tools for agents

## Setup

```bash
cp .env.example .env.local
# GROQ_API_KEY=...
npm install
npm run dev
```

## Research mode (Evidence Mind)

1. Choose **Research**
2. Describe your idea (product, audience, problem)
3. Canvas fills with claim / competitor / market / gap / evidence nodes
4. Lock a validation decision
